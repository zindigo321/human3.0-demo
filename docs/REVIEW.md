## 静态复查结论

| 维度 | 结论与依据 |
|---|---|
| 安全性 | 密钥仅在服务端环境；访谈及规则以不可信数据传入模型；输入、输出、引文严格校验；服务监听回环地址并校验 Host/Origin |
| 数据兼容 | 新项目采用 schemaVersion 1；未知格式与断裂关联导入被拒绝；历史分支、规则、快照及用户修订独立保留 |
| 错误处理 | 模型认证/格式/引文/超时错误有可读反馈；保存和导入失败不清空已有内容；弹窗内保留错误及草稿 |
| 资源 | 请求取消传到上游；结束时释放定时器及响应监听；缓存有容量和时间限制，浏览器事件有卸载处理 |
| 规范与范围 | 职责拆分为领域、规则、演示、持久化、模型适配、报告和界面；没有账号、支付、公开部署或真实个人样例 |
| 类型安全 | TypeScript 检查通过；外部和持久化边界使用 Zod 运行时校验；关键关联再作领域验证 |

## 保留的实际边界

- 未提供真实模型凭据，没有验证真实服务连接、模型语义质量、服务商计费或生产环境提示注入抵抗能力。替身测试只证明本地适配器及约束传递路径。
- 演示模式只整理原文和追问，不给自动层级。四个保护场景验证了原文、情境与未知项，不能推定所有真实模型都会正确理解这些场景。
- 四象限证据必须来自对应主题回答。这是保守的产品约束；理想生活或其他主题里的相关经历需在对应主题补充。
- 本地存储不加密，不提供多设备同步和同时编辑冲突合并。分析最多 200 条回答、请求最多 2 MB、备份导入最多 5 MB。
- 幂等缓存仅限当前服务进程、有效期和容量内。取消请求不能保证服务商不对已开始的计算计费。
- 浏览器文档预览通过，Word/LibreOffice 精确分页、字体替换与编辑后的重排尚未验证。
