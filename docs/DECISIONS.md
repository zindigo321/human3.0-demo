# 第一版产品与工程决策

日期：2026-10-21。执行基线为用户提供的完整需求。压缩包中五个技能用于需求枚举、工程拆分、R0–R5 测试与代码审查；模型名称和外部派发方式不作为本项目依赖。

| 决策 | 原因与影响 |
|---|---|
| 单用户、本地浏览器与本地 Node 服务 | 只监听回环地址；不加入账号、支付、社区、多人协作或公开部署 |
| React + TypeScript + Vite，Express，Zod | UI、业务数据、模型边界、报告职责分离；固定依赖版本 |
| localStorage 单快照自动保存 | 无额外数据库运维；同一浏览器与地址刷新恢复。容量有限，提供 JSON 备份及保存错误反馈 |
| 修改历史回答建立新分支 | 原回答及后续保持可追溯；新分支只继承修改点之前的有效上下文 |
| 规则与评估快照不可变 | 改规则与补充回答使原评估过期；保留当时依据与规则，不偷偷重算历史结果 |
| 用户修订单独保存 | 模型建议可比较；重新分析产生新快照，迁移修订须由用户选择 |
| 优先级与行动计划的主目标分开 | 优先级可描述需要改善的领域，主目标可以是该领域中的具体实践；编辑任一字段不覆盖另一个 |
| 四象限引文限定为对应访谈主题 | 第一版保守限制，避免把其他主题陈述直接当作该象限证据；理想生活与优先级用于行动计划。需要补充证据时切到相应主题作答 |
| 单个核心问题与主题轮换 | 优先收集实际经历，控制单事件深挖；结束前记录近期优先事项 |
| 演示模式不自动赋予层级 | 无真实凭据时只展示保守线索、真实引文与待了解项；模板追问不冒充语义能力 |
| 真实模型仅服务端调用 | 环境变量提供密钥；浏览器、会话备份、源码与常规日志不保存密钥 |
| 模型请求绑定版本并限流于交互 | 仅提交回答或明确重新分析触发；取消、超时、幂等与过期响应保护减少重复调用 |
| DOCX 使用实际文字与表格 | 报告可继续编辑，且包含版本、原文证据、用户修订与行动安排 |
| 测试使用虚构数据和独立浏览器环境 | 不将真实用户访谈作为默认样例，不清理用户的存储 |

## 约定及限制

四象限分别判断，层级与阶段分开保存。行为锚点是产品解释而非官方量表。保护原则见 `SOURCES.md`，在自定义规则之上生效。任何验证结果都区分真实代码、模型替身与真实外部模型调用。

浏览器本地存储未加密；备份包含访谈原文。清理浏览器数据或更换站点地址不会自动迁移历史，应先导出 JSON。JSON 导入按完整数据集替换当前本地视图，导入前先校验全部关联；需要保留多个备份时自行保存到文件。

本应用不是多标签页协同系统。不同标签页同时编辑的冲突不在第一版解决范围内，应在一个标签页中编辑。

对应主题限制是本产品的数据校验选择，不是 Human 3.0 原模型的要求，也不意味着同一实际经历不能涉及多个领域。该经历可以在对应主题再次说明。

真实模型可能产生不可靠推断：结构及引文校验能拒绝格式错误或虚构引文，但不等于证明判断正确。用户可查看证据、修订判断和保留未知项。
